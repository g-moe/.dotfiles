# Better Time

A local Raycast extension for Unix timestamps.

## Commands

- **Now** (`no-view`) — copies `Date.now()` (Unix ms) to the clipboard.
- **To ISO** — shows ISO 8601 for a Unix ms argument, or for now when empty.
  Copy actions for ISO and Unix ms are available in the action panel.

## Run locally

```sh
cd packages/raycast/better-time
npm ci
npm run dev
```

Run `npm run typecheck` for the direct TypeScript check.
Run `npm run build` for the production Raycast build.

`raycast-env.d.ts` is generated by Raycast and excluded from formatting.

From the repository root, `npm run raycast install` installs every Raycast
extension from its own lockfile, and `npm run raycast dev` starts all of them.
Run `npm run raycast check` to test, typecheck, build, and format-check every
extension.
