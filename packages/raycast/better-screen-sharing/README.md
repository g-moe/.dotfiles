# Better Screen Sharing

A local Raycast extension with one **Connections** command.

Selecting it launches Apple Screen Sharing when needed and focuses its
**All Connections** window.

The extension preferences provide five optional machine slots. Each slot has a
display name and a hostname or IP address. Complete slots appear below
**Connections**.

Selecting a machine focuses its open Screen Sharing window. If it is not open,
the extension opens its `vnc://` address and accepts Apple's sign-in dialog
once when saved credentials are already filled in. It accepts Apple's default
screen-sharing type in either dialog order, and returns only after the viewer
exists. Machine actions require Raycast's Accessibility permission.

The extension does not use Full Disk Access, System Events, or stored
credentials. Raycast needs Accessibility access for both machine and
All Connections window focusing.

## Run locally

```sh
cd packages/raycast/better-screen-sharing
npm ci
npm run dev
```

Run `npm run typecheck` for the direct TypeScript check.
Run `npm run build` for the production Raycast build.
Run `npm test` for the zero-dependency control-flow tests.

`raycast-env.d.ts` is generated by Raycast and excluded from formatting.

From the repository root, `npm run raycast install` installs every Raycast
extension from its own lockfile, and `npm run raycast dev` starts all of them.
Run `npm run raycast check` to test, typecheck, build, and format-check every
extension.
