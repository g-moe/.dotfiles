# Default

Build the page the user asked for: options, a comparison, an explainer, a report, a demo, or anything else that fits one HTML file.

Copy [../assets/template.html](../assets/template.html) and replace its sample header, tabs and sections with the content. Give each section one `nav` button whose `data-tab` matches the section's `id`. For a page with one part, drop the `nav` and keep one `<section class="active">`.
