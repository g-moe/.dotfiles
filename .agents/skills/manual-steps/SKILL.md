# Manual Steps

Use this skill only after explicit invocation with `$manual-steps`. Do not invoke it implicitly.

Create a guide from referenced work (code, tests, files, task history, experiments, proofs of concept, bug fixes, or completed agent work). Treat sources as research, not as a required build order or trusted implementation.

Before drafting a guide, read [build-guide-template.md](references/build-guide-template.md). It defines the required artifact structure and content.
