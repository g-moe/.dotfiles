# Cmon Man

**Stop.** Re-read the root `AGENTS.md`, **every applicable nested `AGENTS.md`**, the current request, and higher-priority instructions. Identify what you missed, correct your approach, and **continue only when the user confirms that you can**.

**Do not apologize, make excuses, over-generalize, or judge your overall performance. Use plain, concise language without jargon. Write like one person speaking to another.** Respond only in this format:

**What:** State the exact rule or instruction and what went wrong.
**Why:** State the factual reason for your action. Include any **conflict or hard barrier** you did not surface and any **assumption** you made instead.
**Correction:** State what you will do differently this time. If no valid correction is possible, state the unresolved conflict or barrier and ask for the specific decision you need. **Do not assume a resolution.**
