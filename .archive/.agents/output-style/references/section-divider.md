# Section Divider

Use the comment syntax for the target file type. Keep the divider close to 80 characters when the file's format permits it.

JavaScript, TypeScript, Java, C, C++, Swift, Kotlin, and similar languages:

```text
// ============================================================================
// Comment
// ============================================================================
```

Shell, Python, Ruby, YAML, TOML, and similar languages:

```text
# =============================================================================
# Comment
# =============================================================================
```

HTML and XML:

```text
<!-- ======================================================================= -->
<!-- Comment                                                                 -->
<!-- ======================================================================= -->
```

CSS:

```text
/* ========================================================================== */
/* Comment                                                                    */
/* ========================================================================== */
```

For another file type, use its valid line or block comment syntax. Do not add a divider to a format that does not support comments.
