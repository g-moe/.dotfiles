# Box

Use Unicode box-drawing characters. Make each line the same display width. Connect all corners and edges. Size the box to its longest line.

```text
┌─ OpenAI ───────────────────────────────┐
│  Weekly: 93% left                      │
│  Resets: Sep 3, 11:26 AM CDT           │
│  Reset credits: 1                      │
│    1. Expires Sep 20, 7:27 PM CDT      │
└────────────────────────────────────────┘
```

Use this form when there is no title:

```text
┌──────────────────────────────┐
│  Content                     │
└──────────────────────────────┘
```
