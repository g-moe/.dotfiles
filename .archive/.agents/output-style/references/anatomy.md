# Anatomy

Label the parts of one item. Keep labels aligned with the part they describe.

```text
https://api.example.com:443/users?active=true
└─┬─┘   └──────┬──────┘ └┬┘ └─┬──┘ └────┬────┘
scheme         host      port  path      query
```

Use a legend when direct labels do not fit. Label inferred parts as assumptions. Do not change the item to make the labels easier to align.
