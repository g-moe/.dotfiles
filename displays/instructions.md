# BenQ RD280U portrait

1. Open **Settings → Displays** in BetterDisplay.
   1a. Select the BenQ with serial number **L8R0056001Q**.

2. Open **Display EDID → Load Custom EDID → Load EDID Data**.
   2a. Load `benq-rd280u-portrait.bin`.
   2b. Select **Apply Custom EDID Now**.

3. Open **System Configuration and Flexible Scaling**.
   3a. Turn on **Edit the system configuration of this display model**.
   3b. Turn on **Custom scaled resolutions**.
   3c. Add a resolution with width **1366** and height **1707**.
   3d. Select **Apply**.
   3e. Complete the activation step shown in BetterDisplay.

4. Set the monitor rotation to **90°**.
   4a. Select **1707 × 1366 HiDPI at 60 Hz**.

5. On the monitor, select **System → Display Mode → Aspect**.
   5a. Keep the input at **3840 × 2560, 60 Hz**.

6. Set the other BenQ to **1707 × 2560 HiDPI at 60 Hz**.
   6a. Set its rotation to **270°**.
   6b. Turn mirroring off.
   6c. Arrange the displays.
